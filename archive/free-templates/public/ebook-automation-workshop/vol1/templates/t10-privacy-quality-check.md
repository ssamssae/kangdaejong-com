# 템플릿 10. 개인정보·품질 점검표

Vol1 「AI 자동화 작업장」 부록용 공개 템플릿입니다. 복사해서 문서, 스프레드시트, Notion 데이터베이스로 옮겨 쓰면 됩니다.

## 1. 외부 발송 전 기본 점검

| 점검 항목 | 빈칸 | 예시 기입본 |
|---|---|---|
| 결과물 종류 | [작성] | 고객 문의 답변 |
| 발송 채널 | [작성] | 카카오톡 채널 |
| 고객 이름 포함 여부 | [작성] | 이름 1회 포함 |
| 금액 포함 여부 | [작성] | 180,000원 포함 |
| 날짜 포함 여부 | [작성] | 7월 3일 포함 |
| 개인정보 포함 여부 | [작성] | 전화번호 없음, 주소 없음 |
| 사람이 최종 확인했나 | [작성] | 확인 완료 |

## 2. 개인정보 제거표

| 원본에 있는 정보 | AI 입력에 넣어도 되나 | 안전한 처리 |
|---|---|---|
| 고객 이름 | 필요한 경우만 | 김민지 → 고객 A |
| 전화번호 | 넣지 않음 | 삭제 |
| 주소 | 대부분 넣지 않음 | 동 단위까지만 |
| 결제 정보 | 넣지 않음 | 금액만 사용 |
| 건강 상태 | 매우 주의 | 일반 표현으로 바꾸기 |
| 계약서 원문 | 넣기 전 검토 | 필요한 조항만 요약 |

## 3. 품질 점검 체크리스트

- [ ] 가격, 날짜, 운영시간이 최신이다.
- [ ] 고객 이름과 요청 내용이 맞다.
- [ ] 개인정보가 불필요하게 들어가지 않았다.
- [ ] "무조건", "100%", "보장" 같은 과장 표현이 없다.
- [ ] 내가 제공할 수 없는 약속이 없다.
- [ ] 법률, 세무, 의료 판단처럼 전문가 확인이 필요한 표현이 없다.
- [ ] 외부 발송은 사람이 직접 한다.

## 4. 예시 기입본

원본 문의:

```text
김민지 고객님이 010-****-**** 번호로 문의.
7월 3일 저녁 7시에 필라테스 체험 가능 여부와 가격 문의.
허리 통증이 있어도 가능한지 질문.
```

AI에 넣을 안전 입력:

```text
고객 A가 7월 3일 저녁 7시 필라테스 체험 가능 여부와 가격을 문의했습니다.
허리가 불편한 초보자도 가능한지 물었습니다.
전화번호는 사용하지 않습니다.
```

## 5. 완성형 점검 프롬프트

```text
아래 메시지를 고객에게 보내기 전에 개인정보와 품질 관점에서 점검해 주세요.
수정이 필요한 부분은 이유와 함께 표시하고, 더 안전한 문장으로 바꿔 주세요.

업종: 필라테스 스튜디오
발송 채널: 카카오톡 채널
발송 목적: 체험 수업 문의 답변

보낼 메시지 초안:
"김민지님, 7월 3일 저녁 7시 체험 수업 가능합니다. 허리 통증도 저희가 잘 해결해 드릴 수 있으니 걱정하지 않으셔도 됩니다. 체험은 30,000원이고 오늘 바로 예약하시면 확실히 좋아지실 거예요."

점검 기준:
1. 개인정보가 꼭 필요한 만큼만 들어갔는지
2. 건강 효과를 과장하거나 보장하지 않는지
3. 가격과 날짜가 명확한지
4. 고객에게 부담을 주는 표현이 없는지
5. 사람이 최종 확인해야 할 항목이 무엇인지

출력 형식:
- 위험한 표현
- 수정 제안
- 최종 발송용 안전 문장
- 사람이 다시 확인할 항목
```

## 6. 최종 발송용 안전 문장 예시

```text
김민지님, 문의 주셔서 감사합니다.
7월 3일 저녁 7시 체험 수업은 현재 예약 가능 여부를 확인해 드릴 수 있습니다.
허리가 불편하신 경우 첫 수업에서 상태와 운동 경험을 먼저 여쭙고, 무리 없는 동작부터 안내드립니다.
체험 수업료는 30,000원입니다.
예약을 원하시면 가능한 연락처와 성함을 남겨 주세요. 최종 가능 여부 확인 후 안내드리겠습니다.
```
