## 4. 로그를 보고 답변 초안을 만드는 프롬프트

```text
너는 1인 사업자의 고객응대 기록 정리 도우미입니다.
아래 고객응대 로그를 보고 오늘 먼저 처리할 일을 정리해 주세요.

운영 기준:
- 상태가 "새 문의"이면 답변 초안이 필요합니다.
- 상태가 "입금 대기"이면 다음 확인 시각을 제안해 주세요.
- 환불·변경 문의는 자동 답변 대신 사람이 직접 확인하도록 표시해 주세요.
- 고객에게 보낼 문장은 짧고 정중하게 작성해 주세요.

고객응대 로그:
1. 2026-06-28 / 카카오톡 채널 / 한미라 / 예약 / 입금 대기 / 계좌 안내 후 내일 오전 확인 / 7월 3일 14시 2명
2. 2026-06-28 / 네이버 톡톡 / 오세준 / 환불·변경 / 답변 완료 / 고객 답변 대기 / 전날 변경 요청, 50% 환불 규정 안내
3. 2026-06-28 / 카카오톡 채널 / 이수진 / 단체 문의 / 새 문의 / 단체 가능 여부 확인 / 회사 워크숍 8명

출력 형식:
1. 오늘 우선 처리 3개
2. 고객별 다음 행동
3. 바로 보낼 수 있는 답변 초안
4. 사람이 직접 확인해야 할 항목
```

## 5. 마감 전 체크리스트

- [ ] 새 문의 상태가 남아 있지 않다.
- [ ] 입금 대기 고객의 다음 확인 시간이 적혀 있다.
- [ ] 환불·변경 문의는 규정을 확인했다.
- [ ] 네이버와 카카오톡 문의가 같은 표에 들어 있다.
- [ ] 내일 다시 볼 고객을 표시했다.
