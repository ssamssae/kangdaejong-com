## 2. 제안서 구성

| 섹션 | 들어갈 내용 |
|---|---|
| 인사 | 문의에 대한 감사와 현재 이해한 목표 |
| 제안 요약 | 어떤 결과물을 만들지 3줄로 정리 |
| 작업 범위 | 포함 항목과 제외 항목을 분리 |
| 일정 | 자료 수령일, 초안일, 수정일, 완료일 |
| 견적 | 금액, 부가세 포함 여부, 결제 조건 |
| 다음 단계 | 고객이 회신해야 할 질문 |

## 4. 완성형 프롬프트

```text
아래 상담 정보를 바탕으로 고객에게 보낼 제안서 겸 견적서 초안을 작성해 주세요.
말투는 친절하지만 너무 영업적으로 과장하지 마세요.
고객이 바로 이해할 수 있게 포함 범위와 제외 범위를 분리해 주세요.

고객명: 라온공방
요청 서비스: 네이버 스마트스토어 상세페이지 문구 작성
고객의 목표: 신제품 도자기 컵 판매 시작
내가 제공할 범위:
- 상품명 후보 5개
- 상세페이지 문구 1종
- 구매 전 FAQ 5개
- 1회 수정 반영
제외할 범위:
- 제품 촬영
- 상세페이지 디자인
- 광고 집행
- 스마트스토어 등록 대행
납기: 자료 수령 후 영업일 5일 내 1차 초안
견적 금액: 550,000원, 부가세 별도
결제 조건: 착수금 50%, 완료 후 잔금 50%
고객에게 확인할 질문:
- 현재 제품 사진을 보유하고 있는지
- 주요 구매 고객이 누구인지
- 참고하고 싶은 브랜드나 상세페이지가 있는지

출력 형식:
1. 메시지로 바로 보낼 수 있는 제안문
2. 작업 범위 표
3. 일정 표
4. 견적 및 결제 조건
5. 고객에게 물어볼 질문 3개
```

## 5. 발송 전 확인

- [ ] 금액과 부가세 표기가 맞다.
- [ ] 포함 범위와 제외 범위가 분명하다.
- [ ] 일정이 내가 실제로 지킬 수 있는 수준이다.
- [ ] 고객에게 불리하거나 모호한 약속이 없다.
- [ ] 최종 발송은 사람이 직접 한다.
