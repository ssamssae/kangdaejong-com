## 분배 결정 프롬프트

```text
아래 작업을 자율, 검토, 승인 중 어디에 둘지 판단해줘.

작업 설명:
[작업 설명]

판단 기준:
- 외부로 공개되거나 발송되는가?
- 결제, 구독, 비용 증가가 생기는가?
- 삭제, 초기화, 되돌리기 어려운 변경인가?
- 개인정보, 비밀값, 고객 자료가 포함되는가?
- 같은 파일을 다른 에이전트가 작업 중인가?
- 실패해도 로컬에서 쉽게 되돌릴 수 있는가?

출력:
1. 처리 등급:
2. 추천 담당:
3. 승인 필요 여부:
4. 작업 범위:
5. 금지 사항:
6. 완료 근거:
```

## 기본 규칙 문장

```text
에이전트는 초안 작성, 내부 정리, 로컬 검증은 자율로 처리할 수 있다.
외부 발송, 결제, 배포, 삭제, 개인정보·비밀값 처리, 되돌리기 어려운 변경은 사람 승인 전까지 실행하지 않는다.
작업 범위가 명확하지 않으면 시작하지 말고 범위를 먼저 질문한다.
완료 보고에는 결과, 변경 범위, 검증 근거, 남은 위험을 포함한다.
```
