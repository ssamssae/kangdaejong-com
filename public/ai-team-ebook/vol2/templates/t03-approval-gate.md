# AI 팀 운영 템플릿 03 - 승인 게이트 체크리스트

Vol2 「혼자서 AI 팀 운영하기」 부록용 공개 템플릿입니다. 외부 영향이 있는 행동을 하기 전에 멈추고 사람 승인을 받기 위한 양식입니다.

## 승인 필요 행동

아래 중 하나라도 해당하면 실행 전에 멈추고 사람 승인을 받습니다.

- [ ] 외부 사람에게 메시지, 이메일, 댓글, 게시물을 보낸다.
- [ ] 공개 웹사이트, 스토어, 저장소, 문서에 반영한다.
- [ ] 결제, 구매, 환불, 구독 변경, 유료 API 사용량 증가가 생긴다.
- [ ] 파일 삭제, 데이터 초기화, 계정 설정 변경처럼 되돌리기 어렵다.
- [ ] 개인정보, 고객 자료, 비밀값, 인증 정보가 포함된다.
- [ ] 자동화가 반복 실행되어 비용이나 발송이 누적될 수 있다.
- [ ] 작업 범위가 불명확하거나 다른 에이전트와 충돌할 가능성이 있다.

## 빈 승인 요청 양식

```text
[승인 요청]

작업 ID:
요청자:
하려는 행동:
대상:
외부 영향:
되돌릴 수 있는가:
비용 발생 여부:
개인정보·비밀값 포함 여부:
검증한 내용:
실패 시 영향:
승인 후 실행할 정확한 내용:
승인 없이는 하지 않을 것:
```

## 예시 작성본

```text
[승인 요청]

작업 ID: P-014
요청자: 메인 에이전트
하려는 행동: 완성된 글을 공개 블로그 임시글로 등록
대상: 프로젝트 블로그
외부 영향: 공개 전 임시글이지만 웹 관리자 화면에 저장됨
되돌릴 수 있는가: 삭제 가능하지만 게시 설정 실수 시 공개될 수 있음
비용 발생 여부: 없음
개인정보·비밀값 포함 여부: 없음으로 확인
검증한 내용: 실제 전화번호, 계정명, 토큰 형식 문자열이 없는지 확인
실패 시 영향: 비공개 초안이 잘못 공개될 수 있음
승인 후 실행할 정확한 내용: 임시글로만 저장하고 공개 버튼은 누르지 않음
승인 없이는 하지 않을 것: 공개 발행, 외부 공유, 알림 발송
```

## 에이전트용 중지 문구

```text
다음 행동은 사람 승인 전까지 실행하지 마라:
- 외부 발송
- 공개 게시
- 결제 또는 구독 변경
- 배포
- 삭제 또는 초기화
- 개인정보, 비밀값, 고객 자료 처리
- 되돌리기 어려운 변경

해당 행동이 필요하면 실행하지 말고 승인 요청 양식으로 보고하라.
```
