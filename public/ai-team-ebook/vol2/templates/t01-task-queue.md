## 상태값 기준

| 상태 | 의미 | 다음에 할 일 |
|---|---|---|
| 대기 | 아직 아무도 시작하지 않음 | 담당을 정하거나 에이전트가 집을 수 있게 둔다 |
| 진행 중 | 누군가 작업 중 | 같은 범위를 다른 에이전트에게 주지 않는다 |
| 검토 필요 | 작업은 끝났지만 확인이 필요 | 사람 또는 메인 에이전트가 결과를 확인한다 |

| 보류 | 정보 부족, 승인 대기, 위험 발견 | 이유를 적고 새 작업 배정을 멈춘다 |

## 작업 등록 프롬프트

```text
아래 요청을 일감 큐에 넣을 수 있는 작은 작업으로 쪼개줘.

요청:
[여기에 하고 싶은 일을 적는다]

조건:
- 작업 하나는 30~90분 안에 끝날 크기로 나눈다.
- 각 작업마다 작업 ID, 작업 범위, 완료 조건, 검증 방법을 적는다.
- 외부 발송, 결제, 배포, 삭제, 개인정보 처리가 필요한 작업은 "승인 필요"로 표시한다.
- 실제 계정명, 전화번호, 토큰, 개인 식별자는 쓰지 않는다.
```

## 사용 체크리스트

- [ ] 작업 ID가 겹치지 않는다.
- [ ] 작업 범위가 파일, 문서, 기능 단위로 좁혀져 있다.
- [ ] 완료 조건이 모호하지 않다.
- [ ] 완료 근거가 비어 있는 작업은 완료로 바꾸지 않는다.
- [ ] 승인 필요한 작업은 실행 전에 멈춘다.
