# 사진꾸러미 — 로컬 출시 준비 버전

T-260925-002 → T-260925-004. 인물·셀카 / 쇼핑몰 상품 / 음식·숙소가 한 계정과 크레딧을 공유한다. 기본 보정은 실제 sharp 처리다. 결제·메일·생성형 adapter는 구현했지만 이번 검증은 모의 공급자이며 실제 서비스 연동·공개 출시는 완료하지 않았다.

## 실행과 데이터

Node 22.13 이상(검증 26.5), 단일 프로세스. 기존 Astro 홈페이지·로고 Worker와 독립되어 있다.

```sh
cd photo-app
npm ci
npm start
# http://127.0.0.1:4387
```

`PORT`와 `PHOTO_DATA_DIR`로 포트와 데이터 위치를 바꾼다. 기본 `data/`는 Git 제외. 디렉터리 0700, SQLite 파일 0600, WAL·foreign keys·secure_delete를 사용한다. SQLite 옆 `.lock`이 중복 실행을 막는다. 비정상 종료 뒤에는 해당 PID와 DB 사용 프로세스가 없는지 확인한 후 그 DB의 잔여 lock만 제거한다. 실행 중인 DB의 lock은 제거하지 않는다.

루프백 origin과 바인딩만 지원한다. 공개 서버에 바로 올릴 수 있는 버전이 아니다. 기본 상태에서는 외부 서비스가 모두 꺼져 있고 비밀번호 기반 로컬 가입·무료 3크레딧만 동작한다.

## 구현

- 카테고리별 3개 스타일과 강도. 기본 밝기·채도 보정은 1크레딧. 밝기 곡선은 흑백 끝점을 유지해 하이라이트 손실을 줄인다. 형태·얼굴·상품 글자를 재생성하지 않는다. 상품 스타일은 채도를 바꾸지 않는다.
- JPEG/PNG/WebP 단일 프레임, 입력 10MB·24MP 이하. EXIF 방향 정규화·GPS 등 메타데이터 제거, 긴 변 2400px 이하 PNG. 투명도 유지. PNG·ZIP 다운로드와 비교 슬라이더, 스타일 20개 저장.
- scrypt 비밀번호, 세션 해시만 저장, HttpOnly/SameSite Strict, Host/Origin·사진 소유자 검사, CSP·요청 제한. 외부 기능은 이메일 인증을 요구한다. Resend adapter로 15분·한 번만 쓰는 인증/복구 링크를 보내며 비밀번호 변경 시 모든 세션을 폐기한다. 같은 이메일 무료 체험 반복을 줄이기 위한 해시 180일 정책은 출시 검토안이다. 별칭·다중 이메일 남용을 완전히 막지는 못한다.
- 크레딧 지급 건별 만료·차감 배분·환급 원장. 가까운 만료부터 사용하며 요청 키+입력 지문으로 재차감 방지. 로컬 실패·중단은 한 번만 환급. 생성형 외부 접수가 불명확하면 자동 재요청·즉시 환급하지 않고 결과 확인 상태로 남긴다.
- 완료 사진·요청키는 7일 보관. 실행 시작과 분당 정리, 다운로드 시 만료 검사. 7일 지난 외부 확인 대기는 사진을 지우고 예약을 해제한다(이미 만료된 이용권을 연장하지 않음). 외부 공급자 사본의 삭제를 보장하는 기능은 아니다.
- 충전팩 서버 결제 확인/조회/전액 환불, 프로 빌링키 AES-256-GCM 보관·월 지급·갱신·다음 결제 해지. 성공 URL이나 웹훅 body를 신뢰하지 않고 인증된 서버 조회 결과의 주문/금액/통화/결제키/상태를 대조한다. 재전송·늦은 웹훅은 중복 지급하거나 취소 건을 되살리지 않는다. 결제된 잔액을 쓰기 전에도 서버 상태를 조회한다.
- 환불 요청 시 미사용 지급 건을 먼저 동결한다. 일부 사용·부분 취소·불일치는 검토 상태로 두고 추가 소비를 막는다. 네트워크가 끊긴 청구는 동일 주문을 조회하며 임의 재청구하지 않는다. 명시적 거절·장기 미확인 갱신의 고객 복구 화면은 출시 잔여다.
- 계정에 결제 이력이 없으면 관련 행을 삭제한다. 모든 주문이 취소된 계정은 로그인·메일·사진·스타일을 삭제하고 가명 계정 및 주문을 남긴다. 미해결 주문의 탈퇴·법정 보관·운영자 정산 절차는 공개 전 확정해야 한다.

## 외부 연결 설정 — 기본 비활성

키를 명령 기록·Git·보고에 넣지 않는다. 기존 안전한 시크릿 저장소에서 해당 프로세스로만 전달한다. 이 저장소에 실제 키나 `.env`를 생성하지 않았다.

| 기능 | 환경 변수 | 현재 제한 |
| --- | --- | --- |
| 메일 | `PHOTO_MAIL_ENABLED=true`, `PHOTO_RESEND_KEY`, `PHOTO_MAIL_FROM` | 발신 도메인 확인 및 실제 수신 검증 필요 |
| 결제 | `PHOTO_PAYMENTS_MODE=test`, `PHOTO_TOSS_SECRET_KEY`, `PHOTO_TOSS_CLIENT_KEY` | `test_sk_`/`test_ck_`만 허용, live 키 거부 |
| 구독 | `PHOTO_BILLING_ENCRYPTION_KEY` | 32바이트 hex, 백업·키 교체 절차 필요 |
| 테스트 갱신 | `PHOTO_AUTO_RENEWALS=true` | 기본 꺼짐, 앱 실행 중 분당 확인 |
| 생성형 | `PHOTO_AI_ENABLED=true`, `PHOTO_FAL_KEY` | 활성화하면 실제 유료 API 호출 가능, 예산 승인 필요 |

결제·AI 모드는 메일 기능도 필요하다. 기존 이메일 없는 로컬 계정을 자동으로 상용 계정으로 승격하지 않는다. 승인된 연동 시험은 별도 데이터 디렉터리와 확인한 본인 이메일을 사용한다. 상시 서비스·공개 터널·새 스케줄러는 만들지 않았다.

공급자 후보는 **fal.ai FLUX.1 Kontext Pro** (`fal-ai/flux-pro/kontext`). 인물 잡티/공간 조명은 3, 상품 흰 배경은 5크레딧 초안이며 고정 보존 지시를 사용한다. 외부 전송 동의를 받으며 결과를 다시 조회해 보관한다. 고정 HTTPS 공급자 주소만 접근하고 미디어 다운로드에 키를 전달하지 않는다. 형태·정체성·글자 보존은 프롬프트만으로 보장할 수 없어 실사진 평가 전 최종 모델로 확정하지 않았다. 원근 보정은 제공하지 않는다.

## 가격과 원가

| 이용권 | 가격 초안 | 지급/수명 초안 |
| --- | ---: | --- |
| 무료 | 0원 | 인증된 이메일 최초 3크레딧 |
| 충전팩 | 4,900원 | 30크레딧 / 365일 |
| 프로 | 월 19,900원 | 150크레딧 / 다음 월 결제일까지, 미이월 |

`node scripts/cost-model.mjs`는 가정 계산기다. 1MP API $0.04·환율 1,500원·재시도 15%·PG 3.5%·장당 인프라 10원 가정에서 프로를 전부 3크레딧 AI로 쓰면 부가세 제외 매출 대비 변동원가 약 26.1%다. 고해상도·무료 체험 획득비·메일·고객지원·개발/고정비·환불 손실은 별도이며 실제 이익률이 아니다. 실측 원가 후 가격과 크레딧을 확정한다. 상세 공식 출처와 미확인은 [연동 검토](INTEGRATIONS.md)를 참고한다.

## 검증

```sh
npm test
npm audit --omit=dev
# 저장소 루트에서 npm ci 후
npx playwright test --config photo-app/playwright.config.mjs
npx playwright test --config photo-app/playwright.commerce.config.mjs
```

기본 UI 4개는 모의 API 없이 데스크톱/모바일에서 실제 업로드→보정→비교→PNG/ZIP→삭제를 검사한다. 추가 상용 UI 2개는 **메일·결제 SDK/서버·AI 공급자만 모의**로 대체하고 인증→지급→환불→구독→해지→스타일→생성형 결과 복구→비밀번호 재설정을 검사한다. 모의 수신함은 `test/commerce-serve.mjs`에만 존재한다. 테스트 서버와 임시 DB·브라우저는 검사 종료 시 정리한다.

실사진 기본 보정 표본은 공개 NASA 인물과 CC0 커피 사진으로 한정했다. 하이라이트 손실 수정 후 CPU 처리 중앙값 약 20~22ms(512×512/600×400, 6회)였다. 업로드·큐·네트워크가 빠진 로컬 처리값이며 전체 지연이나 실제 AI 품질 결과가 아니다. 독립 상품 라벨·숙소 실내·다양한 피부/조명 평가는 남아 있다. `scripts/quality-check.mjs`로 허가된 추가 입력을 같은 방법으로 비교할 수 있다.

## 공개 출시 전 남은 조건

- fal 실호출 사진 비교(정체성·텍스트·상품 형태), 실제 해상도/재시도/비용 측정과 모델 확정. 공급자·하위 처리자 보관기간/삭제/지역/표시 의무 확정.
- Toss의 해당 상품/도메인 및 자동결제 계약 범위 확인, 실제 테스트 환경의 결제창·웹훅·지급·환불·갱신 실패 실측. 모의 검증만으로 PG 심사 완료를 주장하지 않는다.
- Resend 발신 도메인·실제 수신/복구 확인, 추가 가입 남용 방어, 만료/환불·사업자/문의처·개인정보 고지 확정.
- 공개 TLS 호스팅·영속 저장/백업·작업큐·모니터링·비밀 키 교체·운영자 조정/복구 및 정기 청구 운영. 현 로컬 Origin/단일 프로세스 제한을 검토 없이 제거하지 않는다.
- 사용자 승인 후 공개 배포·유료 API 지출·판매 활성·실결제. 현재 해당 외부 실행 승인은 없다.
