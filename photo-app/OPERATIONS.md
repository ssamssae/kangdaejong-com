## 정지 상태 백업과 복구

Node 22.16 이상. 백업 대상 DB에는 사진 BLOB·계정·크레딧·주문·암호화된 빌링키가 포함된다. 키 원문은 별도 안전한 저장소에서 관리한다. 이 파일을 Git·공개 호스팅·지원 첨부에 올리지 않는다.

1. 신규 작업·주문 접수를 중지하고 진행 중 작업과 외부 결과 미확인 주문을 확인한다. 해당 앱 프로세스만 정상 종료한다. 실행 중 `.lock`을 삭제하지 않는다.
2. `node scripts/backup.mjs /private/data/photo.sqlite /private/backups/new-snapshot`을 실행한다. 목적지는 새 디렉터리여야 한다. 도구는 앱과 같은 lock을 잡고 SQLite backup API로 WAL을 포함한 일관된 스냅샷을 만들며 무결성·외래키 검사, SHA256을 남긴다. 디렉터리0700/파일0600이며 기존 파일을 덮어쓰지 않는다.
3. 백업은 민감 데이터다. 외부 보관을 시작하기 전 암호화 저장소·접근자·보존기간·삭제 절차를 확정한다. 현재 스크립트는 암호화나 자동 업로드를 하지 않는다.
4. 원본을 덮어쓰지 않고 빈 격리 디렉터리에 복사한다. manifest SHA256을 먼저 대조한다. 앱과 동일한 코드 버전, 별도 보관한 해당 빌링 암호화 키 버전을 확보한다.
5. 네트워크/메일/결제/자동갱신이 없는 격리 환경에서 시작한다. 로그인·사진 바이트·크레딧 잔액·요청키 중복 방지를 확인한다. 만료 자료는 앱 정리 경로로 삭제하며 삭제 요청 기록도 복구본에 재적용한다.
6. 복구본을 실제 운영에 연결하기 전 PG 주문 현재 상태와 대조한다. 과거 백업의 유료 크레딧을 바로 소비하거나 과거 청구를 다시 실행하지 않는다. 운영 전환·재시작은 승인된 배포 절차에서만 수행한다.

`test/backup.test.mjs`는 가상 계정/사진으로 백업→재개 후 사진 바이트·잔액·중복 차감 방지, 실행 중 거절, 기존 목적지 보호, 손상 DB 실패 시 정리를 실제 검사한다. 이는 로컬 복구 검증이며 원격 장애 복구나 실사용자 DB 복구 완료가 아니다. 키 교체 복구, 암호화 원격 보관, 복구시간 목표, 운영 자동화는 미확정이다.

## AI 품질·원가 실측 실행표

- 대상 후보: Recraft V3 image-to-image 또는 배경 교체. [공식 API 가격](https://www.recraft.ai/docs/api-reference/pricing) 9/26 확인: 40 units/$0.04 per image, 1000 units/$1. 초기 계획 최대4회·160 units/$0.16. 추가 충전·자동 재시도 없음.
- 기존 제안의 선행 조건: 공급자 서비스 사용범위 답변, 외부 전송 가능한 시험 이미지. 인물은 별도 동의가 있는 자료만 사용한다. 기존 NASA 인물 표본은 로컬 전용으로 유지한다.
- 입력 4종: 인물(정체성·피부질감), 글자 있는 상품(라벨·색·형태), 음식(재료·수량), 실내(벽·창문·가구 구조). 카테고리별 1장은 초기 결격 검사이며 품질 보증이나 통계적 성공률이 아니다.
- 입력/출력 원본 SHA256, 모델/endpoint/파라미터, 시작/종료 시각, 입력/출력 크기, 요청 전후 잔액과 동시 계정사용 여부를 기록한다. 키·사람 이름·서명된 결과 URL·메일 본문은 기록하지 않는다. 출력 출처 메타데이터를 제거하거나 공개 게시하지 않는다.
- 요청 전 manifest와 비용 상한을 고정한다. 타임아웃/접수 불명은 재제출하지 않고 상태·차감을 확인한다. 공유 계정의 동시 사용이 있으면 잔액 차이를 해당 시험 단가라고 확정하지 않는다.
- 검토표: 각 입력의 보존 항목, 명령 준수, 깨짐/환각, usable/rejected와 이유를 원본·결과 비교로 작성한다. 중대 형태/글자 오류는 해당 기능 출시 보류로 판정한다.
- 실효 API 원가 = 시험에서 확인한 전체 차감 units / 사용 가능 결과 수 / 1000 USD. 실패·재시도 비용을 포함하며 사용 가능 결과0이면 단가 미산출·출시 부적합이다. 4/4 성공시 API만 $0.04/사용가능장, 3/4 성공시 약$0.0533/장(가정, 실측 아님).
- `scripts/cost-model.mjs`의 환율·PG율·인프라비는 가정이다. 실제 AI 호출 원가, Toss 계약 수수료, 호스팅/메일/저장소 청구, 환불·지원·무료체험 획득비를 채운 후 가격을 확정한다. 미측정 값을 0원으로 바꾸지 않는다.

## 정책 확정과 출시 조건

[Recraft Developer Terms](https://www.recraft.ai/legal/developer-terms)의 서비스 이용 제한·출처·저장 조건과 문의 답변을 대조한 후 통합한다. 현재 문의가 해결되지 않아 Recraft API 호출/상용 연결을 완료로 표시하지 않는다. 현재 privacy.html의 fal 안내를 미구현 Recraft 연결로 바꾸지 않는다.

- 공급자별 법인·처리국가·전송항목·목적·전송시점·보유기간·삭제요청 경로를 근거와 함께 확정한다. 앱 삭제와 공급자 삭제를 같은 것으로 설명하지 않는다.
- 사업자·문의처, 결제기록 보존 근거/기간, 계정삭제 후 분리보관, 백업 보존/삭제 재적용, 유료 AI 오류·부분사용 환불·구독 갱신 실패 지원 방식을 정한다. 공개 전 법령/계약 대조가 필요하며 현 문구는 출시 준비안이다.
- 현재 루프백 제한을 유지한다. 공개 TLS/영속 저장·큐·헬스체크·알림·복구·비밀키 운영을 실제 호스팅에서 검증해야 한다.
- 사용자 허용 가맹 범위와 실제 운영 검증을 별도로 관리한다. 실사용자 사진 전송, 실결제, 유료 판매 개시는 해당 조건과 승인 범위를 충족한 뒤 진행한다.
