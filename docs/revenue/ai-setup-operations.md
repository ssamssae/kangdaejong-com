현재 페이지는 사전 상담용이며 결제·예약 접수가 아니다. 문의는 방문자가 이메일 앱에서 직접 전송한다. 홈페이지가 문의를 수신했다고 표시하지 않는다. 폼 선택은 브라우저 메모리에서만 처리하며 서버 전송·로컬스토리지·분석 이벤트가 없다.

## 사전 상담

수집할 최소 정보: 컴퓨터 종류/OS 버전, 사용하는 AI 도구, 직접 응답 여부, 텔레그램 사용 여부, 컴퓨터 상시 연결 가능 여부, 원하는 일 한 가지, 상담 가능 시간대. 주민등록번호·주소·비밀번호·OTP·토큰은 받지 않는다. 계정 로그인과 토큰 입력은 고객이 직접 한다. 고객 정보는 공개 저장소에 기록하지 않는다.

고객 메시지 응답은 별도 발신 지시가 있을 때만 수행. 다음은 검토용 답변 구조다: 환경 요약 → 지원 가능 여부/미확인 → 포함/제외 → 총액/일정/지원기간 → 취소환불/결제 수단 → 고객 동의. 아직 설치지원을 수행하지 못하는 환경에는 결제를 요청하지 않는다.

## 납품 확인

1. 고객 기존 앱·세션·설정의 시작 상태를 기록하고 백업 범위에 동의받는다.
2. 최소 권한과 전용 봇으로 설치하며 기존 서비스와 포트·폴더를 분리한다.
3. 비민감 고유 표식으로 요청/응답 왕복과 정확한 세션을 확인한다.
4. 이번 설치 대상만 정상 중지/재시작하고 새 요청 응답을 확인한다.
5. 허용 채팅 제한과 시크릿 파일 권한을 확인한다. 증거에는 비밀값 대신 PASS/FAIL만 남긴다.
6. 시작·중지·업데이트·복구·삭제 안내와 포함/제외 범위를 전달한다.
7. 고객과 인수 항목을 확인하고 지원 종료일을 기록한다. 미완료는 납품 완료로 표시하지 않는다.

거래별로 익명 ID, 유입 경로, 문의일, 적합 판정, 결제일/금액, 환불, 수수료, 실제 정산, 직접비, 설치시간, 지원시간, 인수 여부를 비공개 기록한다. 결제·정산·이익을 혼용하지 않는다.
