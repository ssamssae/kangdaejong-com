# 홈페이지 구성

T-261003-016부터 프로젝트 시기별 1.0/2.0/3.0 탐색을 없애고 `/` 한 페이지로 통합했다.

- 프로젝트, 생활 앱, 책, 연락 순으로 보여준다.
- `/archive/`는 홈으로 이동하며 기존 책·설치·기분 앵커는 계속 열린다.
- 앱·책·브릿지 목록은 `src/data/home.ts`, 서비스 목록은 `src/data/project-versions.ts`의 `currentProjects`를 사용한다.
- 사용자가 이용하는 상세·법적·지원 URL은 보존한다.

검증 경로와 배포 연결은 [feature-map.md](feature-map.md)의 단일 페이지 홈페이지 절을 따른다.
