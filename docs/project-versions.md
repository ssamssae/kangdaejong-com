# 홈페이지 프로젝트 버전

앱 자체의 릴리스 번호가 아닌 프로젝트 시기 구분이다. 사용자 기준은 입타 이전=1.0, 입타부터 현재=2.0.

- `/`: 현재 2.0. 입타, 콜타, 로고꾸러미, 사진꾸러미. 서비스 실제 제공 범위를 카드에 명시한다.
- `/archive/`: 1.0 기존 목록. 기존 책·앱·공개 도구 링크와 `#books` 유지. 입타는 2.0에서 소개한다. 기존 archive 검색 제외 설정은 유지한다.
- 3.0: 미래 구분만 표시하며 링크나 출시일은 만들지 않는다.

`src/data/project-versions.ts`가 버전 탐색과 현재 프로젝트 소개 데이터다. 새 2.0 프로젝트는 currentProjects에 추가한다. 3.0을 시작할 때는 당시 2.0 화면·프로젝트를 별도 고정 경로에 보존한 뒤 versions의 2.0 href를 해당 경로로, 3.0 href를 메인으로 바꾼다. ProjectVersions current와 홈페이지 제목·소개도 같이 전환한다. 기존 1.0 경로와 개별 서비스 URL은 유지한다.
